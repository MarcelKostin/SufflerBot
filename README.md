# Бот аренды микронаушника-суфлёра

## Структура проекта

```
souffler_bot/
├── main.py              # точка входа
├── config.py            # токен, цены, условия
├── states.py            # состояния диалога
├── keyboards.py         # инлайн-клавиатуры
├── storage.py           # хранение заявок в JSON
├── handlers/
│   ├── start.py         # /start и приветствие
│   ├── rental.py        # весь диалог оформления заявки
│   └── admin.py         # переписка админа с клиентом
├── requirements.txt
├── .env.example
└── .gitignore
```

## 1. Локальная настройка (VS Code)

1. Откройте папку `souffler_bot` в VS Code.
2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv venv
   venv\Scripts\activate      # Windows
   source venv/bin/activate   # macOS/Linux
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и заполните:
   - **BOT_TOKEN** — получите у [@BotFather](https://t.me/BotFather) командой `/newbot`.
   - **ADMIN_ID** — ваш числовой Telegram ID, узнать можно у [@userinfobot](https://t.me/userinfobot).
4. Запустите бота:
   ```bash
   python main.py
   ```
5. Напишите вашему боту `/start` в Telegram — должен прийти привет с кнопками услуг.

## 2. Как работает диалог с клиентом

1. `/start` → выбор услуги (день / день + суфлёр).
2. Клиент вводит дату аренды.
3. Если выбрана услуга с суфлёром — выбор длительности (кнопки по 1.5 ч или свой вариант).
4. Выбор типа залога (деньги / студенческий).
5. Клиент оставляет контакт (кнопка «Отправить контакт» или текстом).
6. Показывается итоговая сводка → кнопка «Отправить заявку».
7. Вам как админу приходит структурированное сообщение с заявкой.

## 3. Как отвечать клиенту

Просто сделайте **Reply** (ответить) на сообщение с заявкой в чате бота — то, что вы напишете,
автоматически уйдёт клиенту от имени бота. Так можно логировать всю переписку о встрече прямо
в истории заявки.

## 4. Деплой на BotHost

1. Залейте содержимое папки `souffler_bot` в репозиторий на GitHub (файл `.env` заливать **не нужно** — он в `.gitignore`).
2. В личном кабинете BotHost создайте проект из GitHub-репозитория.
3. В настройках проекта на BotHost укажите переменные окружения:
   - `BOT_TOKEN`
   - `ADMIN_ID`
4. Как точку запуска укажите `main.py`.
5. Запустите проект — бот должен подняться на постоянку (polling).

## 5. Настройка цен и условий

Все суммы и условия аренды редактируются в одном месте — `config.py`:
```python
PRICE_DAY = 700
PRICE_HELPER_BASE = 700
PRICE_HELPER_BLOCK = 1000
HELPER_BLOCK_HOURS = 1.5
DEPOSIT_MONEY = 3000
```

## 6. Хранение заявок

Все заявки сохраняются локально в `applications.json` (создаётся автоматически) —
удобно, если понадобится выгрузить историю или посчитать статистику.
Если BotHost использует эфемерную файловую систему (файлы стираются при перезапуске),
и вам важно не терять историю — дайте знать, добавим сохранение в внешнюю БД
(например, SQLite на диске с постоянным томом, либо Google Sheets/Airtable).
